Chaque essai a un protocole, un critère de réussite, la décision qu'il nourrit et ce qui arrive s'il échoue. Les résultats iront dans `docs/essais/` avec le matériel, le navigateur et l'état du cache (tes consignes §17). Machine de référence : Windows 11 ; Chrome, Edge et Firefox s'y mesurent ; Safari se mesure sur un Mac ou reste marqué « non mesuré ». Tant qu'un essai n'est pas fait, rien n'est « mesuré ».
