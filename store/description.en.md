# Os-x86

The x86 emulation feature of Kazo OS. It runs x86 virtual machines in the browser (v86): a Linux guest, FreeDOS, and Windows programs through Wine. Other apps use it through the `Os-x86.Interface` contracts package; the Windows app for users is BoxedWine, installed separately.

Milestone 0 (in progress): the `x86` command, Linux shell in the terminal, console Windows and DOS programs in the terminal, per-program network permission.
