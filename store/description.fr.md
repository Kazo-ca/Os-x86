# Os-x86

La fonctionnalité d'émulation x86 de Kazo OS. Elle fait tourner des machines virtuelles x86 dans le navigateur (v86) : un Linux invité, FreeDOS, et des programmes Windows par Wine. Les autres apps l'utilisent par le paquet de contrats `Os-x86.Interface` ; l'app Windows destinée à l'usager est BoxedWine, installée à part.

Jalon 0 (en cours) : la commande `x86`, un shell Linux dans le terminal, des programmes Windows et DOS console dans le terminal, la permission réseau par programme.
