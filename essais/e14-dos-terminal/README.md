# Essai E14 — DOS et console dans le terminal (prototype jetable)

Simulateur du terminal de Kazo (`terminal.html` + `terminal.js`) au-dessus de v86 0.5.473 : grille texte 80x25 (redimensionnable) alimentée soit par la mémoire texte VGA (voie « VGA », `get_text_screen` ou lecture brute), soit par un petit émulateur VT branché sur ttyS1 (voie « pty ») ; entrée limitée au jeu de touches d'une commande Terminal de Kazo (sans F1-F12 ni Alt ; option `?chord=1` : Échap+lettre = Alt+lettre, Échap+chiffre = F-touche). Résultats : `docs/essais/e14-dos-terminal.md`.

- **Image DOS** : `pwsh -File download-freedos.ps1` (FreeDOS 1.4 LiteUSB et LiveCD depuis freedos.org, SHA-256 vérifié, données non fiables dans `images/dl/`), `docker build -t e14-mtools -f Dockerfile.mtools .`, puis `python -I make-dos-image.py` → `images/dos.img` (32 Mio ; FDAUTO.BAT sans installateur, `\E14\` avec KEYTEST/GUESS/GFX .COM assemblés à la main, CHOICE, DEBUG, FIND).
- **Image Debian + Wine (console)** : `pwsh -File build.ps1` (recette E17 + `wine-stable-dev`, mingw, socat, kbd, nano, less, vim-tiny ; `guest/consoletest.c` compilé en PE par winegcc) → image Docker `e14-wine-console`, `images/wine-fs.json` + `images/rootfs-flat/` (~25 min, ~3 Go de tar temporaire).
- **Mesure automatique** : `npm install` puis `node run.mjs --guest dos --runs 3 --port 8166` et `node run.mjs --guest wine --runs 3 --port 8167` → `results-<guest>-<n>.json`, captures `images/e14-*.png`.
- **Pilotage à la main** : `node drive.mjs --guest dos|wine --port 8162 --ctl 8163 [--headed]` puis `POST /keys`, `/cmd`, `GET /screen`, `/stats`, `/set?poll=16&route=pty`, `/shot?name=x&term=1`, `/cpu`, `/mem`, `/quit` (voir l'en-tête de `drive.mjs`). Scripts invités : `guest/vga-run.sh` (programme sur tty1) et `guest/pty-run.sh` + `guest/pty-child.sh` (programme dans un pty socat relié à ttyS1, code de sortie écrit à la fin). `run.mjs` injecte les scripts de `guest/` dans `/root/e14/` par 9p au démarrage (pas besoin de reconstruire l'image après les avoir modifiés ; `cache=loose` : toujours un nom de fichier neuf).
- `lib/` (libv86.js, v86.wasm, seabios.bin, vgabios.bin de v86 0.5.473) n'est pas versionné ici : copier `essais/e1-wine-v86/lib/`.
- Ports 8160 à 8179 ; images Docker `e14-*` seulement.
